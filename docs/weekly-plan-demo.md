# Демонстрация плана на неделю

Консольное демо использует учебный каталог и отдельную базу SQLite. Выполните команды из корня проекта в PowerShell.

```powershell
python -m pip install -r requirements.txt
$env:STATE_PATH = Join-Path $env:TEMP ("moy-shag-plan-" + [guid]::NewGuid() + ".db")
$env:LLM_PROVIDER = "none"
$env:OLLAMA_URL = ""
python -m assistant_bot --demo
```

Для нажатия кнопки введите команду `/click …`, напечатанную в текущем ответе.

| Действие | Что увидеть |
| --- | --- |
| Выберите русский язык и спросите «Как оценить эффективность рекламы кофейни?» | Совет, название учебного источника и кнопка «Составить план на неделю». |
| Выберите «Составить план на неделю» → «30 минут». | План от выбора показателя и настройки учёта до сбора данных, расчёта и сравнения. Расчёт стоимости заказа требует известных расходов и ненулевого числа связанных заказов за те же даты. |
| Нажмите «Начать план» → «Начать действие». | У первого действия есть объект, критерий, оценка времени и заголовок подтверждающего фрагмента. |
| Выберите «Напомнить» → «Через минуту» → «Один раз» → «Сохранить». | Запись появится в `/reminders`. Вернитесь к шагу через `/step`. |
| Выберите «Сделано» → «Получилось частично». Напишите «Выбрали заказы, но нет данных по расходам». | Бот показывает доработку текущего шага с учётом пробела. Следующие шаги остаются в ожидании, прежнее напоминание выключается. |
| Нажмите «Доработать действие». Затем выберите «Сделано» → «Получилось» и введите «Первая кампания: считаем заказы по промокоду за период с 1 по 7 ноября». | Бот сохраняет обе попытки, показывает ближайшее действие и сообщает, если для него нет подходящего нового материала. «Следующее действие» открывает план с обновлённым прогрессом. |

Перезапустите демо с той же `STATE_PATH` и откройте `/plan` и `/reminders`. Прогресс и обе записи результата сохраняются. Консоль позволяет проверить запись расписания и её отключение.

Для короткого плана задайте вопрос «Как проверить спрос до открытия кофейни?». В учебном каталоге подтверждён первый замер потока в выбранной точке. Для проверки предположения о спросе нужны дополнительные наблюдения. Учебный каталог содержит несколько примеров. С подготовленным каталогом кейса запустите `python -m assistant_bot --console` и проверьте повторные продажи, безубыточность, запуск и работу с командой. При дневном лимите 20 минут план запуска предлагает черновики отдельных частей и переносит полноценный анализ рынка и финансовый прогноз.
