# Изменения Ивана — 14 ноября 2026

Это историческая сводка работы Ивана на 14 ноября. Актуальная версия проекта описана в [заметках релиза](RELEASE_NOTES.md).

Рабочая ветка: `codex/sonnet-5-5`. Название сохранено с начала работы; сейчас
бот использует Grok 4.7 через xAI. Переход на Sonnet предусмотрен настройками
OpenRouter. На момент исходной проверки этот вариант не был включён и изменения ещё не попали в `main`.

## Что готово

- Подключена генерация связных ответов через Grok: ответ, источники, следующий
  шаг и критерий выполнения. Приложение проверяет структуру и опорную цитату.
- Импорт расширен на открытые статьи, глоссарий, документы, описания вебинаров,
  подкастов и калькуляторов, карточки курсов и доступные бесплатные уроки.
  Подготовленный каталог содержит 1428 материалов, 1395 с текстом.
- Поиск использует русскую морфологию, BM25, веса заголовков и разделов, проверки
  платформ и тематические синонимы. Для инструкций выбираются шаги, для определений
  — формулы и условия. Слабые дополнительные источники исключаются.
- Добавлен постепенный показ ответа в Telegram и кеш точных повторов на 5 минут.
  Кнопки действия появляются после проверки полного ответа.
- Бот перенесён на отдельную серверную службу с автозапуском. Состояние сохранено,
  локальный экземпляр остановлен. Подготовлены [unit и инструкция](deploy/README.md).
- Доступ к внешней модели ограничен согласованным тестовым чатом, сроком и бюджетом.
  Счётчик API-попыток на сервере сохраняется между перезапусками.

Платные и подписочные уроки и пользовательские таблицы не входят в контекст LLM.
Документы представлены описаниями, видео и аудио не транскрибировались. Каталог,
исходный дамп, SQLite и ключи в Git не загружены.

## Что проверено

Прошли **53 автоматических теста**. На 62 вопросах проверен подбор контекста;
на 13 вопросах проведено парное сравнение генераций одной моделью с одинаковыми
настройками. Доставка Telegram в эти замеры не включена.

| Показатель | До | После |
|---|---:|---:|
| Медианный объём контекста | 6248 символов | 3002 символа |
| Медиана входных токенов | 3741 | 2787 |
| Медиана полного ожидания, 13 пар | 15,66 с | 16,45 с |
| 90-й процентиль ожидания | 29,42 с | 18,79 с |

**Сокращение типичного ожидания не доказано.** В этом прогоне уменьшились объём
контекста и долгие задержки; некоторые ответы стали менее подробными в отдельных
аспектах. Найденную потерю формулы NPS исправили и закрепили тестом. Проверка
цитаты не доказывает правильность всех утверждений, актуальные законы отдельно
не проверялись. Результат одного прогона зависит от нагрузки API и случайности
генерации.

## Как посмотреть

1. Переключиться на ветку `codex/sonnet-5-5` в GitHub или локальном клоне.
2. Прочитать README для запуска демо на синтетических данных без секретов и дампа.
3. После установки зависимостей выполнить `python -m unittest discover -s tests -v`.

Работающий бот: [@moy_shag_demo_bot](https://t.me/moy_shag_demo_bot).
Внешняя LLM сейчас разрешена только для тестового чата Ивана; это не публичный
доступ для всех участников. На 14 ноября согласовано отдельное 24-часовое окно
с 30 новыми API-попытками. Реальные параметры доступа хранятся только на сервере.

Следующие направления: более широкий независимый тест качества, проверка
вариантов снижения задержки самой LLM и проверка доступности выбранного Sonnet
перед сменой провайдера. Обещание «все ответы быстрее без потери качества»
результаты пока не подтверждают.
