# 15 основных сценариев

[Результаты выполненных живых прогонов и ограничения](core15-results.md).

В `core15.json` зафиксированы вымышленные условия, исходная и другая естественная
формулировка, профиль, ограничения и смысловые критерии. Проверяются:
реклама без заявок, сравнение стоимости заявки, повторные покупки, жалоба,
безубыточность, кассовый разрыв, бизнес-план, спрос на услугу, тест новинки,
найм, текучесть, применимость KPI, налоговое уточнение, границы описания документа
и доработка частичного результата.

Локальная проверка на подготовленном каталоге:

```bash
python scripts/evaluate_core15.py --catalog data/catalog.jsonl --report core15-report.json
```

Это 30 проверок источников и структурных свойств планов, без API и Telegram.
Для двух сценариев правильное поведение — уточнение или честное ограничение
по содержимому документа, а не искусственный недельный план.
Проверки не доказывают фактическую правильность сгенерированного ответа.

Живой прогон требует отдельного разрешённого бюджета, постоянного счётчика и
того же тестового чата. Сравнивайте реальные ответы с полями `required` и
`forbidden`; записывайте версию кода, каталога, модель и настройки. Сначала
исходные вопросы, затем другие формулировки. Кеш при измерении очищается.
Результаты старой редакции нельзя переносить на изменённый промпт или поиск.
Нельзя публиковать полный каталог, дамп, исходные фрагменты или личные данные.

Для частичного результата дополнительно проходят существующие UI-тесты
`test_partial_outcome_rework_then_success_preserves_results_and_continues`:
повтор остаётся на текущем действии, история сохраняется, напоминания прошлой
попытки отключаются, переход вперёд требует явного завершения и подтверждения.
