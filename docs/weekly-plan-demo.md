# Демонстрация плана на неделю

В консольном демо используются учебные материалы. Действия, результат и напоминания сохраняются в SQLite. Запустите эти команды из корня проекта в PowerShell. Демо откроет новую временную базу.

```powershell
python -m pip install -r requirements.txt
$env:STATE_PATH = Join-Path $env:TEMP ("moy-shag-plan-" + [guid]::NewGuid() + ".db")
$env:LLM_PROVIDER = "none"
python -m assistant_bot --demo
```

В консоли вместо нажатия кнопки введите напечатанную рядом с ней команду `/click …`. Команды с идентификаторами берите из текущего сообщения.

| Действие | Что увидеть |
| --- | --- |
| Выберите русский язык (`/click lang:ru`) и спросите «Как оценить эффективность рекламы кофейни?» | Совет с источником и кнопка «Составить план на неделю». |
| Нажмите «Составить план на неделю». Когда бот уточнит время, выберите «30 минут» или напишите «30 минут в день». | Предложение на семь дней. Пять действий распределены по дням 1, 2, 3, 5 и 7. Для каждого указана примерная длительность. |
| Нажмите «Начать план», затем «Начать действие». | «План на неделю» (`/plan`) и «Моя задача» (`/step`) показывают одно текущее действие с оценкой времени, критерием и источником. |
| Нажмите «Напомнить» → «Через минуту» → «Один раз» → «Сохранить». | Запись появится в «Напоминаниях» (`/reminders`). Откройте `/step`, чтобы вернуться к действию. |
| Отметьте «Сделано» и «Получилось частично». Напишите «Выбрали заказы. Пока учитываем только заявки с сайта». | Бот сохраняет частичный результат, предлагает доработку и показывает учебный практикум «Рекламный тест для малого бизнеса» с объяснением выбора. |
| Нажмите «Доработать действие». После доработки выберите «Сделано» → «Получилось» → «Пропустить» → «Следующее действие». | Прогресс меняется на «Выполнено 1 из 5 действий». Следующий шаг предлагает добавить метку или промокод для каждого объявления и показывает исходный материал. Учебный практикум уже предложен при доработке. Связанное напоминание отключается. |

Завершите демо и запустите `python -m assistant_bot --demo` снова из того же окна PowerShell. Откройте `/plan` и `/reminders`, чтобы проверить сохранение прогресса и расписания. Для проверки отказа и замены задайте новый вопрос, например «Как проверить спрос до открытия кофейни?», и запросите ещё один план. Отказ сохраняет текущую работу. Замена вступает в силу после отдельного подтверждения.
