# Единый релиз — 14 ноября 2026

Ветка: `release/unified-bot`. Объединены ядро `codex/sonnet-5-5`, интеграция
`feat/telegram-language-menu` и новый `main` с исправлением первого напоминания.
Основная ветка и исходная ветка Ивана при сборке не изменяются.

## Интерфейс

Сохранено новое меню main: «Задать вопрос», «Мой шаг», «Напоминания», «Помощь»,
«Что умеет бот», «Контекст бизнеса», «Язык». Поддерживаются `/start`, `/menu`,
`/help`, `/about`, `/language` и прежние команды. Выбор языка хранится отдельно
для каждого чата. Материалы остаются на языке исходного каталога; английский
поиск покрывает ограниченный словарь типовых запросов.

## Исправления

- Первый запрос на напоминание после выбора языка возвращается в общий
  обработчик сообщений и запускает настройку напоминания, а не поиск материала.
- Уточняющий вопрос LLM сохраняет исходную задачу. Короткие ответы и повторные
  уточнения продолжают её; новая явная задача и `/cancel` завершают старое уточнение.
- При недоступной модели, истёкшем окне, исчерпанном бюджете и недостатке сведений
  остаются релевантные бесплатные/платные карточки. Дубли URL-кнопок исключены.
- Состояние принимает записи старого серверного бота с `topic`, main с `language`
  и объединённой версии с обоими полями. Сохранённые шаги и напоминания не сбрасываются.
- Разные чаты обслуживаются параллельно, сообщения одного чата — по порядку.
  Общая очередь и число запросов чата ограничены. Статусы/уточнения LLM изолированы,
  резервирование бюджета и доступ к кешу защищены от конкуренции.
- Явные персональные раскрытия блокируются до API. Это ограниченные эвристики,
  не обещание полного обезличивания. Разрешён только прежний тестовый доступ.

## Проверки

Запуск: `python -m unittest discover -s tests -v` после установки зависимостей.
Новые регрессии проверяют сохранение уточнений после переоткрытия SQLite,
отдельность чатов, карточки при ошибке LLM, совместимость состояния, порядок
очереди, обработку ошибок, изоляцию статусов параллельных генераций, лимит
API-попыток и остановку очевидного персонального ввода.

Локальные тесты используют синтетические данные и заглушки API. Успешный прогон
не означает, что проверены все ответы Grok или чистая Docker-сборка.

Локальный прогон релиза: **77 тестов прошли**. Структура главного меню, кнопок
выбора языка/стадии и тексты основных экранов совпадают с `main` версии `a55abff`.

## Обновление сервера

Перед переключением сохраняются текущая версия, unit, приватная конфигурация
и согласованные SQLite-копии состояния и бюджета. Код размещается в новом
каталоге версии; данные и разрешённое окно Grok сохраняются. Переключается только
наша служба. Значения токенов, chat ID и рабочий каталог в Git не включаются.

После обновления существующий пользователь открывает `/menu` или `/start`,
чтобы получить новое меню. Выбор языка доступен через `/language`.

Старый код без поля `language` не читает состояние, сохранённое новой версией:
откат требует совместимого обработчика состояния или согласованного возврата
к резервной копии. Очередь запросов находится в памяти; graceful shutdown
завершает принятые запросы, аварийное завершение может потребовать их повтора.
