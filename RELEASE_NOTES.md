# «Мой шаг» · релиз 15 ноября 2026

В релиз объединены ветка `release/unified-bot` и более новые улучшения `main`.
Интерфейс Telegram сохраняет выбор языка, команды и идентификаторы прежних кнопок.

## Что изменилось

- Однозначные термины вроде NPS и ROI получают определение из глоссария без
  обращения к модели. Для «Маркетинг» бот спрашивает, какой результат нужен.
  Для темы без подтверждённого материала сообщает о пробеле.
- Поиск распознаёт простые разговорные вопросы об эффективности рекламы и
  проверке бизнес-идеи. Точный запрос шаблона или таблицы выделяет подходящие
  карточки документов. Описание файла обозначается как ограниченный контекст.
- «Мой бизнес» позволяет отдельно выбрать стадию и сферу и увидеть часовой пояс.
  Последний совет можно открыть повторно. Текущая задача и её напоминания
  сохраняются, пока пользователь явно не подтвердит замену.
- Уточнения модели продолжают исходную тему. Новый самостоятельный вопрос
  меняет тему, `/cancel` отменяет текущий ввод. При сбое или недоступности
  модели бот сообщает об этом и показывает подходящие карточки с ценами и
  ссылками из каталога.
- Локальный фильтр проверяет вопрос, минимальный профиль, препятствие, фрагменты
  и итоговое тело запроса. Он маскирует известные форматы персональных данных
  и сохраняет деловые суммы и даты. При отказе проверки API и бюджет
  не затрагиваются. Цитата сверяется с отправленным очищенным текстом.
  Правила не обеспечивают полного обезличивания.

## Что проверено

- **89 автотестов** прошли в чистом окружении Python 3.14 на Windows. Они покрывают
  повторный запуск SQLite, совместимость старых профилей, порядок и лимиты
  очереди, параллельные чаты, сохранение бюджета и завершение работы.
- Из официального дампа локально собрано **1 428 материалов, 1 395 с доступным
  текстом или описанием**. Дамп и каталог хранятся вне Git.
- [36 сценариев](evaluation/README.md) прошли на учебных и официальных данных:
  **24/24** проверок поиска в каждом каталоге и **12/12** проверок логики на
  заглушках. Проверки не оценивают фактическое качество ответов внешней модели.
- [GitHub Actions](https://github.com/zyounky/moy-shag-telegram-bot/actions/workflows/ci.yml)
  проверяет тесты, учебный сценарий, чистую Docker-сборку и состояние между
  запусками под непривилегированным пользователем. На Windows этой сборки Docker
  отсутствует. Реальные Telegram-сеансы, платный API и задержка доставки
  в этой проверке не запускались.

## Обновление

Новые переменные, зависимости, модель NER и ручная миграция SQLite не нужны.
Сохраните действующие настройки, файлы состояния и бюджета и согласованное
окно внешней модели. Действия для выделенной серверной службы перечислены
в [HANDOFF.md](HANDOFF.md).
